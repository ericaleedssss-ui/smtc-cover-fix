# Rhine Go M7 实机性能验收

实测日期 2026-11-15。被测应用基于 M6 提交 `c13def0`，运行于 Windows 的 Type-C 副屏。用户通过应用界面登录网易云。测试版用临时 Go overlay 加入窗口定位和测量脚本，应用的渲染和播放路径沿用该提交。

脚本静音播放曲目，从首页打开选歌墙，切换到歌曲详情，切换下一首，再回首页，共五轮。墙、详情、首页各按现有动画时长统计 580、340、500 毫秒内画面有变化的 MyGo 帧。帧耗时来自 `MYGO_FRAME_STATS=all`，p95 对每轮样本按最近秩计算。这里的 fps 是应用渲染日志计数除以时长，屏幕实际扫描输出未另行测量。

| 指标 | 目标 | 结果 | 结论 |
| --- | --- | --- | --- |
| 打开选歌墙 | ≥120 fps，p95 ≤8.3 ms | 77.6、153.4、141.4、137.9、151.7 fps，p95 4.9–7.8 ms | 首轮 fps 未达标 |
| 进入歌曲详情 | ≥120 fps，p95 ≤8.3 ms | 144.1–161.8 fps，p95 1.5–2.8 ms | 达标 |
| 返回首页 | ≥120 fps，p95 ≤8.3 ms | 144.0–148.0 fps，p95 5.3–7.2 ms | 达标 |
| 切歌最慢帧 | ≤33 ms | 五轮最慢 11.5 ms | 达标 |
| 暂停后首页空闲 | 0 帧 | 15.001 秒内 0 帧 | 达标 |
| 流程完成后的常驻工作集 | ≤300 MB | 间隔约 1 秒的 15 次读数为 226.96–261.47 MB，中位数 228.07 MB | 达标 |

选歌墙首轮在 580 毫秒内记录 45 帧。最宽的帧间隔为 77.5 毫秒，其后的单帧工作耗时为 3.6 毫秒。现有统计未覆盖这段帧间等待，仍需区分渲染调度、系统调度与显示等待。返回首页有一帧 40.6 毫秒，其中呈现阶段为 29.3 毫秒。全程峰值工作集为 418.64 MB。

原始帧日志、工作集采样和逐轮 CSV 位于相邻的 `rhine-go-artifacts/M7/` 目录。M7 为验收记录，应用源代码未改动。
