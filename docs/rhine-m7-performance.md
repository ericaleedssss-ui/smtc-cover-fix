# Rhine Go M7 实机性能验收

实测日期 2026-11-15。被测应用基于 M6 提交 `c13def0`，运行于 Windows 的 Type-C 副屏。用户通过应用界面登录网易云。测试版用临时 Go overlay 加入窗口定位和测量脚本，应用的渲染和播放路径沿用该提交。

脚本静音播放曲目，从首页打开选歌墙，切换到歌曲详情，切换下一首，再回首页，共五轮。墙、详情、首页各按现有动画时长统计 580、340、500 毫秒内画面有变化的 MyGo 帧。帧耗时来自 `MYGO_FRAME_STATS=all`，p95 对每轮样本按最近秩计算。这里的 fps 是应用渲染日志计数除以时长，屏幕实际扫描输出未另行测量。

| 指标 | 目标 | 结果 | 结论 |
| --- | --- | --- | --- |
| 打开选歌墙 | ≥120 fps，p95 ≤8.3 ms | 77.6、153.4、141.4、137.9、151.7 fps，p95 4.9–7.8 ms | 首轮 fps 未达标 |
| 进入歌曲详情 | ≥120 fps，p95 ≤8.3 ms | 144.1–161.8 fps，p95 1.5–2.8 ms | 达标 |
| 返回首页 | ≥120 fps，p95 ≤8.3 ms | 144.0–148.0 fps，p95 5.3–7.2 ms | 达标 |
| 切歌最慢帧 | ≤33 ms | 五轮最慢 11.5 ms | 达标 |
| 暂停后首页空闲 | 0 帧 | 15.001 秒内 0 帧 | 达标 |
| 流程完成后的常驻工作集 | ≤300 MB | 间隔约 1 秒的 15 次读数为 226.96–261.47 MB，中位数 228.07 MB | 达标 |

选歌墙首轮在 580 毫秒内记录 45 帧。最宽的帧间隔为 77.5 毫秒，其后的单帧工作耗时为 3.6 毫秒。现有统计未覆盖这段帧间等待，仍需区分渲染调度、系统调度与显示等待。返回首页有一帧 40.6 毫秒，其中呈现阶段为 29.3 毫秒。全程峰值工作集为 418.64 MB。

原始帧日志、工作集采样和逐轮 CSV 位于相邻的 `rhine-go-artifacts/M7/` 目录。M7 为验收记录，应用源代码未改动。

## 首次打开选歌墙复测

真实账号在同一副屏复测。标准测试版首轮为 105.2 fps，p95 为 11.0 ms。后四轮为 127.6–155.2 fps，p95 为 5.3–8.1 ms。歌曲详情与返回首页达标，切歌最慢 9.7 ms，空闲 15 秒记录 0 帧，常驻工作集为 176.70–196.78 MB。全程峰值为 447.41 MB。

独立诊断版在临时 MyGo 副本里记录交换链和窗口回调的等待时间。选歌墙首轮为 106.9 fps，p95 为 8.0 ms。前一帧完成后到下一帧完成相隔 131.2 ms，同一间隔内 Windows 的 DXGI 交换链等了 116.6 ms 才收到可继续出帧的信号，UI 回调在信号到达约 1.6 ms 后执行。采样确定了等待发生的位置，信号迟到的原因仍待区分。

另一个隔离实验把交换链允许排队的帧数从 1 提到 2。首轮降到 67.2 fps，p95 升到 27.2 ms，其中一帧在呈现阶段耗费 178.9 ms。此实验未合入。原版、诊断版和实验版的日志分别位于 `rhine-go-artifacts/M7/recheck-1`、`diagnostic` 和 `queue-depth-2`。

## Windows 呈现跟踪的后续诊断

系统级 ETW 会话启动失败，`logman` 返回访问被拒绝，WPR 的 GPU 配置返回 `0xc5585011`。本地采集脚本位于 `rhine-go-artifacts/M7/etw-baseline/capture-windows-present.ps1`，需从管理员 PowerShell 启动。

用 Windows 的 `DwmGetCompositionTimingInfo` 采样桌面整体合成计数，并和临时诊断版的 DXGI 信号时间对齐。四次冷启动的首开依次为 101.7、158.6、148.3、150.0 fps，p95 依次为 11.0、5.6、7.3、7.2 ms。首轮最长应用帧间隔为 135.9 ms，同期交换链信号等待 122.9 ms，而 DWM 的整体合成计数仍从 127 持续推进到 135。这定位到应用交换链排队或信号路径。DWM 的全局计数无法区分该窗口的 GPU 完成、合成提交和实际扫描输出，需要系统级 ETW 继续区分。

| 隔离实验 | 首开 fps | 首开 p95 | 备注 |
| --- | ---: | ---: | --- |
| 动画结束后再加载缓存未命中的封面 | 72.4 | 6.4 ms | 使用了访客数据，未用于真实账号验收 |
| DXGI 呈现同步间隔设为 0 | 115.5 | 8.9 ms | 仍有 118.1 ms 的交换链等待 |
| 开场动画期间暂时停用选歌墙两处玻璃模糊 | 96.6 | 13.1 ms | 真实账号 |

以上实验都未达到首开目标。没有改动正式应用渲染代码。逐帧日志和桌面采样位于 `rhine-go-artifacts/M7/dwm-cold-series`，隔离实验保存在同一 M7 目录。
