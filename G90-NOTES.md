# G90 — filled light layers, uniform album detail and removal of hidden duration work

## Scope and changes

- `maintained/Qt/qml/NowPlayingPanel.qml` and `maintained/Qt/shaders/recordAtmosphere.frag`: More returns beside Share with only one circular background and three genuinely round dots. Order is Like → Comments → Share → More. Keep glass/card bounds unchanged. Wider filled light sheets have nearly opaque interiors and soft edges; source-over composition preserves overlap, rather than a bright thin outline. The field extends farther left and fades toward text. The record's lower/right silhouette blends into the background while top/left rim remains legible; album artwork still alone rotates. Centre is a real transparent small hole with a subtle edge, the existing small contact edge expresses thickness, and sheen is subdued.
- `maintained/Qt/src/PlaylistMagazine.cpp` and `scripts/enable-g90.py`: all album directories use the existing magazine, not just `recordBrowse` albums. Suppress the old native album detail underneath, fixing route-dependent UI versions. Existing comments, subscriptions, search, downloads, row actions and history are reused.
- `maintained/Qt/qml/PlaylistMagazine.qml`: shared album header with artist links/marquee and release date, album description entry, album comment tab and a heat column occupying the otherwise redundant album-name column. Playlist layout/column positions remain. Heat only uses finite 0–100 provider `pop`/`popularity`; zero is valid, unavailable/null/invalid values show `—`, never play counts or invented values. Live API availability may vary.
- `maintained/Qt/src/PlaylistShowcase.cpp/.h`, `maintained/Qt/qml/PlaylistShowcase.qml`: **total duration is removed entirely** from showcase info, computation and automatic metadata completion. There is no replacement total-duration calculation. The previous code repeatedly called `indexOfId` for each song and kept fetching pages every 600 ms merely to complete durations. A hidden preview also converted the entire queue. Both unnecessary background paths are gone; Tab-visible previews and explicitly requested song metadata remain, as do individual track durations and the actual player's duration.
- `scripts/enable-g90.py` carries album-route/normalizer/Windows-check integration; `scripts/apply-maintained.py` runs it. `scripts/verify-build-source.py` checks the new route gate. Workflow changes only human-readable G90 labels/artifact names; compressed patches are unchanged.
- Updated `maintained/G79-ui-checks.cppfrag`, `scripts/fixtures/g71/checks.cpp`, `scripts/test-g71-qml.py`, `scripts/test-g79-model.py`, `scripts/test-g86-qml.py`: enforce requested album UI/no-total-duration contracts, actual heat states, one More surface/order, light movement and lyric protection. Existing meaningful checks remain.
